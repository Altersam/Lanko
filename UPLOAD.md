# Как обновить репозиторий

1. Распакуйте архив.
2. Загрузите **содержимое папки `Lanko-portfolio` в корень** репозитория `Altersam/Lanko`.
3. Разрешите замену существующих `README.md`, `index.html`, `Ins.html`, `microservices.html`.
4. Добавьте новую папку `docs/` целиком.
5. После коммита проверьте `index.html` через GitHub Pages или локально в браузере.

## Что изменится

- `README.md` станет коротким репозиторием-резюме.
- `index.html` станет интерактивной страницей-кейсом.
- старые URL `Ins.html` и `microservices.html` продолжат работать, но будут переводить в структурированные документы `docs/`.
- появится отдельная техническая архитектура и история проекта.

## Что я намеренно не добавлял

- ключи API;
- логины/пароли;
- production-конфигурацию;
- персональные данные;
- полный закрытый исходный код сайта.
