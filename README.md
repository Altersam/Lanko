# Lanko.rf — кейс разработки цифровой экосистемы питомника

> Публичный репозиторий-портфолио проекта [ланко.рф](https://ланко.рф): редизайн и консолидация трёх старых сайтов, перенос и очистка контента, WordPress-тема, каталог щенков, новости и фотоальбомы, услуги и заявки, CRM, кабинет владельца, PWA/Android-обёртка, Telegram-интеграция, SEO и оптимизация скорости.

## Коротко о проекте

У питомника существовали три самостоятельных сайта с разной структурой и накопленными проблемами: дублирование страниц, устаревшая навигация, отсутствие нормальной мобильной версии, битые материалы и ошибки в привязке фотографий. Задача выросла из «обновить сайт» в полноценную цифровую систему, которой владелец может управлять без разработчика.

**Что получилось:** один современный сайт на WordPress + собственный интерфейс управления для телефона + сервисный слой для заявок, календаря, CRM, Telegram, SEO и аналитики.

### Масштаб миграции

| Показатель | Результат |
|---|---:|
| Старых сайтов объединено | **3 → 1** |
| Фотографий обработано и перенесено | **1000+** |
| Карточек собак в исходной миграции | **20** |
| Пород | **7** |
| Статей | **21** |
| Фотоальбомов | **15** |

> Числа выше относятся к первоначальной миграции контента и зафиксированы в истории проекта. Текущий контент production-сайта может изменяться владельцем.

## Что реализовано

### 1. Новый публичный сайт

- единая адаптивная структура вместо трёх сайтов;
- главная страница с баннерами, породами, щенками, услугами, новостями и контактами;
- раздел **«Щенки на продажу»** с карточками и фотослайдерами;
- новости и фотоальбомы в едином формате публикаций;
- динамическая форма заявки на услуги;
- карта и актуальные контакты;
- архив старых сайтов.

### 2. Миграция и нормализация данных

- аудит старых сайтов и выгрузок;
- Python/ETL для разбора исходного контента;
- восстановление соответствия «собака ↔ фотографии ↔ материалы»;
- очистка текстов и битых файлов;
- импорт в WordPress через собственные структуры данных.

### 3. WordPress как CMS, а не конструктор

- кастомная тема;
- Custom Post Types + ACF;
- отдельные сущности для щенков, публикаций и заявок;
- редактируемые настройки питомника;
- собственные REST API endpoints;
- импортёр и упрощённые формы управления контентом.

### 4. Заявки и мини-CRM

- сохранение заявок в базе;
- уведомления;
- статусы **Новая / В работе / Завершена**;
- календарь визитов и периодов передержки;
- представление заявок в формате канбан/списка.

### 5. Кабинет владельца `/app/`

Отдельный мобильный интерфейс, чтобы не работать в стандартной админке WordPress:

- создание и редактирование карточек щенков;
- публикация новостей и фотоальбомов;
- управление баннерами главной;
- обработка заявок;
- календарь;
- установка как PWA;
- Android WebView-обёртка как вариант отдельного APK.

### 6. Telegram-интеграция

- запись клиента на услугу;
- уведомления администраторам;
- напоминания;
- публикация контента;
- поддержка нескольких администраторов;
- Cloudflare Worker как relay для webhook при сетевых ограничениях хостинга.

### 7. SEO, аналитика и производительность

- title/description, canonical, Open Graph и Twitter Card;
- собственный sitemap и robots.txt;
- Schema.org / JSON-LD;
- настройки Яндекс.Метрики и Google Analytics;
- оптимизация LCP/CLS;
- lazy loading, defer, фиксированные размеры изображений;
- WebP/кэширование через инфраструктуру хостинга.

## Важно о коде

Этот репозиторий — **публичное портфолио и документация кейса**, а не полный production source. Исходный код WordPress-темы, настройки сервера, ключи API, персональные данные клиентов и закрытая конфигурация сюда не публикуются.

Это сделано намеренно: показать архитектуру, объём и инженерные решения без раскрытия эксплуатационных секретов и пользовательских данных.
