# Редизайн сайта питомника «Ланко»

Объединение трёх устаревших сайтов многопородного питомника собак в один
современный адаптивный сайт на **WordPress** с переносом контента, наведением
порядка в данных, приёмом заявок, мини-CRM и Telegram-ботом — всё с
возможностью самостоятельного редактирования владельцем.

🔗 **Новый сайт:** [ланко.рф](https://ланко.рф)
📄 **Кейс:** откройте `index.html`

---

## Задача

У питомника было три отдельных сайта — [lanko.ru](https://lanko.ru),
[king.lanko.ru](https://king.lanko.ru), [karavan-iti.ru](https://karavan-iti.ru).
Проблемы:

- громоздкая навигация и десятки разрозненных страниц;
- часть страниц не открывалась, встречались битые ссылки;
- перепутанные фотографии (например, фото алабая под записью о японском хине);
- нет мобильной версии и единого стиля;
- нет приёма заявок и онлайн-записи;
- редактировать сайт мог только разработчик.

## Решение

Единый сайт на WordPress из 5 разделов: **Главная · Питомцы · Блог · Галерея ·
Контакты** — с новым дизайном, приёмом заявок, мини-CRM и Telegram-ботом, всё
редактируется в админке.

## Что сделано

| Область | Результат |
|---|---|
| **Платформа** | Перенос с 3 статичных сайтов на одну WordPress-тему (CPT + ACF) |
| **Дизайн** | Кастомная дизайн-система, голубо-зелёная гамма, фон-«пятнышки», полный адаптив |
| **Контент** | 1000+ фото, 20 карточек собак, 7 пород, помёты, 21 статья, 15 альбомов галереи |
| **Данные** | Восстановлена привязка фото к собакам/статьям; удалены битые файлы (0 битых ссылок) |
| **Родословные** | Древо на 3 поколения со ссылками на карточки предков |
| **Галерея** | Альбомы-карточки с лайтбоксом и фильтром по тегам |
| **Услуги** | Передержка, ветуход, груминг, дрессировка + щенки от заводчика |
| **Форма записи** | Динамическая форма, поля подстраиваются под выбранную услугу (даты, кличка, чекбоксы) |
| **Приём заявок** | Заявки сохраняются в БД (CPT), приходят на e-mail; готовность к Amelia |
| **Мини-CRM** | Канбан-доска (Новые / В процессе / Завершённые) + календарь FullCalendar с периодами передержки |
| **Telegram-бот** | Приветствие, запись клиентов, уведомления и напоминания; для админов — публикация новостей и сводки заявок |
| **Несколько админов** | Привязка по @нику с авто-подстановкой chat_id; уведомления всем администраторам |
| **Обход блокировки** | Релей на Cloudflare Worker для webhook, если хостинг режет входящие от Telegram |
| **Редактирование** | Формы «Добавить питомца/статью», импортёр контента и настройки темы прямо в админке |
| **Задел под ИИ** | REST-эндпоинты и функции для ИИ-помощника (DeepSeek/Qwen) |

## Разделы сайта

- **Главная** — описание питомника, породы, щенки, услуги, блог, контакты и форма записи.
- **Питомцы** — древо карточек по породам с родословными и фильтром.
- **Блог** — лента статей с фильтром по рубрикам + карта сайта.
- **Галерея** — альбомы-карточки с лайтбоксом и фильтром по тегам.
- **Контакты** — на главной, с формой записи.

## Telegram-бот

- **Клиентам:** приветствие, пошаговая запись на услугу, услуги и контакты, напоминания о визите.
- **Администраторам:** публикация новости в блог (текст + фото) самой верхней записью,
  сводка последних заявок, визиты и передержки на сегодня, уведомления о новых заявках.
- **Несколько администраторов:** в настройках указываются @ники; chat_id подставляется
  автоматически после первого `/start` (обход ограничения Telegram).
- **Релей:** если хостинг блокирует входящие соединения от серверов Telegram
  (ошибка `Connection timed out`), webhook проксируется через бесплатный Cloudflare Worker.

## Процесс

1. **Аудит** выгрузки трёх сайтов — поиск битых страниц и перепутанных фото.
2. **ETL на Python** — парсинг исходных данных, восстановление привязки фото,
   очистка текстов, сборка единого датасета.
3. **Дизайн и вёрстка** — адаптивные шаблоны, родословное древо, галерея, формы.
4. **WordPress-тема** — кастомные типы записей, ACF-поля, импортёр и
   формы-помощники для самостоятельного наполнения.
5. **Сервисы** — приём заявок, мини-CRM с календарём, Telegram-бот.
