# Питомник Ланко — приложение для хозяйки (APK)

Тонкая Android-обёртка (WebView) над кабинетом `https://ланко.рф/app/`.
Приложение НЕ зависит от Telegram — работает напрямую через сайт.

В приложении доступно:
- **Щенки на продажу** — добавить / скрыть / удалить карточки с фото.
- **Блог** — статьи и фотоальбомы.
- **Заявки (CRM)** — список обращений + смена статуса.
- **Календарь** — визиты и напоминания.

Вход — обычный логин/пароль WordPress (хозяйка уже администратор сайта).

## Перед сборкой

В файле `app/src/main/java/ru/lanko/app/MainActivity.java` проверьте адрес:

```java
private static final String APP_URL = "https://xn--80aubjg.xn--p1ai/app/"; // ланко.рф/app/
```

`xn--80aubjg.xn--p1ai` — это `ланко.рф` в Punycode (так домен пишется в коде).
Если домен сменится — поменяйте здесь и в условии `shouldOverrideUrlLoading`.

## Способ 1. Сборка в облаке GitHub (без установки программ) — рекомендуется

1. Создайте репозиторий на github.com, загрузите туда папку `apk/`
   (вместе со скрытой папкой `.github`).
2. Откройте вкладку **Actions** → workflow **«Build Lanko APK»** → **Run workflow**.
3. Через ~3–5 минут в результатах сборки (Artifacts) появится
   **lanko-app-debug** — это `app-debug.apk`.
4. Скачайте `.apk`, перешлите хозяйке (или установите на её телефон).

> Это «debug»-APK — его достаточно для личной установки.
> Для публикации в Google Play нужна подписанная release-сборка (см. ниже).

## Способ 2. Сборка в Android Studio

1. Установите Android Studio (https://developer.android.com/studio).
2. **File → Open** → выберите папку `apk/`. Дождитесь синхронизации Gradle.
3. **Build → Build Bundle(s)/APK(s) → Build APK(s)**.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Подписанный release-APK (для Google Play или «чистой» установки)
**Build → Generate Signed Bundle / APK → APK**, создайте keystore, выберите
`release`. Получите `app-release.apk`.

## Установка на телефон

1. Перешлите `.apk` на телефон (через файлы / мессенджер / кабель).
2. Откройте файл. Android попросит разрешить установку из этого источника —
   разрешите («Настройки → Установка неизвестных приложений»).
3. Появится иконка «Питомник Ланко» 🐾.

---

## Альтернатива без APK — установить как приложение (PWA)

Если не хочется собирать APK, кабинет можно «установить» прямо из браузера:

1. Открыть на телефоне `https://ланко.рф/app/`, войти.
2. Меню браузера (⋮) → **«Установить приложение»** / **«На главный экран»**.
3. Появится та же иконка и тот же кабинет, в отдельном окне.

PWA и APK открывают один и тот же кабинет — данные общие.
